## The idea

This portfolio is a responsive, interactive space for **Saad Ali**, a BSCS student at the University of Gujrat who is growing toward a career in Artificial Intelligence and software engineering.

It is designed to feel more like a conversation than a resume: motion, clear sections, and real projects invite visitors to explore the work and start a connection.

## What is inside

| Experience | Details |
| --- | --- |
| Animated introduction | Rotating type animation introduces Saad as a developer, AI enthusiast, and problem solver. |
| Particle canvas | A lightweight canvas background adds depth without distracting from the content. |
| Project showcase | Medi_Track, Skill_Track, and DevBlog are presented with features, technologies, and repository links. |
| Skills map | Frontend, backend, WordPress, AI/ML, databases, cloud, security, and Git are represented in dedicated sections. |
| Recommendations | Visitors can submit a recommendation and see it appear with a smooth reveal and confirmation modal. |
| Responsive layout | The page adapts across desktop, tablet, and mobile screen sizes. |

## Run locally

Because this is a static site, there is no build step or dependency install required.

```bash
git clone https://github.com/simplysaadali/My_Portfolio.git
cd My_Portfolio
```

Open `index.html` in a browser, or serve the folder with any local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
